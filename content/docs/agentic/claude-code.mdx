Claude Code works with the [Knowledge Graph section](/docs/agentic#quickstart)
in `AGENTS.md`. This page covers how Claude Code loads that file and how to
let it fetch Knowledge Graph pages without a prompt each time.

## Load AGENTS.md

Claude Code reads `AGENTS.md` when your project has no `CLAUDE.md`. If you
have a `CLAUDE.md`, import `AGENTS.md` from it:

```md title="CLAUDE.md"
@AGENTS.md
```

Reading `AGENTS.md` without an import requires Claude Code v2.1.277 or later.
On earlier versions, use the import.

[More info on CLAUDE.md and AGENTS.md in Claude Code](https://code.claude.com/docs/en/memory)

## Allow fetching Knowledge Graph pages

By default, Claude Code asks before it fetches a web page from a new domain. To
allow the Knowledge Graph for everyone on the project, add a permission rule to
`.claude/settings.json`:

```json title=".claude/settings.json"
{
  "permissions": {
    "allow": ["WebFetch(domain:%SITE_HOST%)"]
  }
}
```

Commit the file so teammates get the same rule. Answering **Yes, and don't
ask again** at the prompt has the same effect for your own sessions.

[More info on permissions in Claude Code](https://code.claude.com/docs/en/permissions)

## Verify the setup

Start a session and run `/context`. `AGENTS.md` appears under **Memory
files**. Then ask:

```text title="Prompt"
Which Knowledge Graph pages apply to this project?
```

Claude fetches `%SITE_URL%/llms.txt`, fills in **Project context** in
`AGENTS.md`, and lists the pages it would use.
