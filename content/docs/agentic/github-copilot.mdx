GitHub Copilot reads `AGENTS.md`, so the
[Knowledge Graph section](/docs/agentic#quickstart) needs no extra setup in
your repository. On GitHub.com, Copilot cloud agent and Copilot code review run
behind a firewall that you need to open for the Knowledge Graph.

## Allow the Knowledge Graph through the firewall

Copilot cloud agent and Copilot code review can only reach allowlisted
addresses. To add the Knowledge Graph:

1. In your repository, open **Settings**.
2. In the sidebar, under **Code, planning, and automation**, click **Copilot**,
   then **Internet access**.
3. Click **Custom allowlist**.
4. Enter `%SITE_URL%` and click **Add rule**.
5. Click **Save changes**.

If you can't add rules, an organization owner needs to set **Allow repository
custom rules** to **Enabled**.

[More info on the Copilot firewall](https://docs.github.com/en/copilot/how-tos/use-copilot-agents/coding-agent/customize-the-agent-firewall)

## Use repository instructions instead of AGENTS.md

If your repository doesn't use `AGENTS.md`, paste the section into
`.github/copilot-instructions.md`. Copilot applies that file to every request
in the repository.

[More info on custom instructions for GitHub Copilot](https://docs.github.com/en/copilot/how-tos/configure-custom-instructions/add-repository-instructions)

## Verify the setup

Assign Copilot cloud agent an issue with this description:

```text title="Issue"
Find the Knowledge Graph pages that apply to this project, and fill in
Project context in AGENTS.md.
```

Copilot fetches `%SITE_URL%/llms.txt`, opens a pull request that fills in
**Project context**, and lists the pages in its description. If it reports a
blocked request, check the firewall allowlist.
