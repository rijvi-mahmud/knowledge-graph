Cursor reads `AGENTS.md` from your project root and subdirectories, so the
[Knowledge Graph section](/docs/agentic#quickstart) needs no extra setup.
Cursor's agent uses its web tool to fetch Knowledge Graph pages when a task
needs them.

[More info on AGENTS.md and rules in Cursor](https://cursor.com/docs/context/rules)

## Verify the setup

Open the agent and ask:

```text title="Prompt"
Which Knowledge Graph pages apply to this project?
```

The agent fetches `%SITE_URL%/llms.txt`, fills in **Project context** in
`AGENTS.md`, and lists the pages it would use. If it answers without fetching
anything, check that `AGENTS.md` is at the project root and contains the
section.

## Use a project rule instead of AGENTS.md

If your project doesn't use `AGENTS.md`, create
`.cursor/rules/knowledge-graph.mdc` and paste the section below this
frontmatter:

```md title=".cursor/rules/knowledge-graph.mdc"
---
description: How to find and follow Knowledge Graph domain specs.
alwaysApply: true
---
```

Project rules must use the `.mdc` extension. Cursor ignores `.md` files in
`.cursor/rules/`.
