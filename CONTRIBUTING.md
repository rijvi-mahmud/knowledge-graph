# Contributing

Thanks for helping build a shared base of software requirements.

## Before you start

Open an issue describing the change first, so we can agree on where it belongs
(core, an industry, or a domain) before you write it up.

## Contributor License Agreement

Every contributor signs the [Contributor License Agreement](./CLA.md) once,
before their first pull request is merged. You keep ownership of your work; the
agreement lets the project stay open source while also offering commercial
licenses, which funds its maintenance.

When you open your first pull request you will be asked to sign it
electronically. If you contribute on behalf of an employer, make sure your
employer has approved this first (see section 3(c) of the agreement).

### Work you did not write

If any part of your contribution is not your own work (copied text, code or
data), say so in the pull request: identify the source, its author and its
license. Do not submit material whose license does not allow redistribution
under this project's licenses.

## Content conventions

Domain content follows the writing rules in [`CLAUDE.md`](./CLAUDE.md):
research every fact from current sources, keep structured facts in
frontmatter, and give every rule its rationale.
